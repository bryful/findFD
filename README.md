# findFD - ファイル・フォルダ再帰検索コンソールアプリ

C++17の標準ライブラリ（`std::filesystem`）を使用した、高速・軽量なコマンドライン検索ツールです。  
指定したパス（省略時はカレントディレクトリ）内のサブディレクトリを含めて再帰的に走査し、ファイル名またはフォルダ名に検索文字列を含む対象の**フルパス**を一覧出力します。

---

## 特長

1. **標準ライブラリのみで実装**: 外部ライブラリ（Boostなど）不要、C++17対応コンパイラがあればビルド可能
2. **日本語・Unicode完全対応**: 日本語のファイル名・パスやコンソール表示で文字化けしません
3. **安全なエラーハンドリング**: 管理者権限が必要なシステムフォルダ等のアクセス拒否（Access Denied）に遭遇してもクラッシュせずスキップして走査を継続
4. **直感的な検索**: デフォルトで大文字・小文字を区別しない（Case-insensitive）検索。オプションで区別する検索も可能

---

## 使い方

```bash
findFD.exe <検索文字列> [検索パス] [オプション]
```

### 引数
- `<検索文字列>` （必須）: ファイル名またはフォルダ名に含まれる部分文字列
- `[検索パス]` （任意）: 検索を開始するディレクトリ（**省略した場合はカレントディレクトリ**）

### オプション
- `-s`, `--case-sensitive`: 大文字と小文字を厳密に区別して検索します（指定しない場合は区別なし）
- `-h`, `--help`: ヘルプを表示します

---

## 実行例

### 1. カレントディレクトリ内を検索（パス省略）
```bash
findFD.exe .cpp
```
出力例:
```text
C:\Users\User\source\repos\findFD\main.cpp
```

### 2. パスを指定して検索
```bash
findFD.exe report D:\Documents
```
出力例:
```text
D:\Documents\2026\monthly_report.xlsx
D:\Documents\reports
```

### 3. 日本語文字の検索
```bash
findFD.exe 議事録 "C:\Users\User\OneDrive - Work"
```

### 4. 大文字・小文字を区別する検索 (`-s`)
```bash
findFD.exe README . -s
```

## ビルド方法

### 方法1: 付属のバッチファイルでビルド（推奨）
Visual Studio がインストールされている環境で、コマンドプロンプトまたは PowerShell から以下を実行します。

```cmd
build.bat
```
自動的に Visual Studio の C++ コンパイラ環境を検出し、最適化オプション付きで `findFD.exe` を生成します。

### 方法2: CMake を使用したビルド
```cmd
mkdir build
cd build
cmake ..
cmake --build . --config Release
```

### 方法3: Visual Studio IDE からビルド
Visual Studio を起動し、「ローカル フォルダーを開く」から本リポジトリのフォルダーを選択すれば、そのままビルド・デバッグ実行できます。
